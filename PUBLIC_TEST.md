# Public test note

This is a public static test copy of the Akatsuki host.

- No key/password gate: the original key auth is only in `server.py`; GitHub Pages serves the static files directly.
- The `hen14.02.iso` is known to be a relabeled 14.00 disc and is not used by the browser host.
- `kernel_1402.bin` is a real 14.02 kernel ELF, but the chain is still unverified.
- Do not run this on a console you cannot recover. Prefer a disposable 14.00/14.02 console.

Host URL: `https://quickky1.github.io/quicks14.02/`
